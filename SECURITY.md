# Security policy

## Supported versions

Security fixes are applied on the latest `main` / released tags as practical for this project.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Instead, contact repository maintainers privately (for example via the host’s security advisory feature on GitHub/GitLab/Codeberg, or maintainer email if published).

Include:

- Description of the issue and impact
- Steps to reproduce
- Suggested fix (optional)

We will acknowledge receipt and coordinate disclosure.
