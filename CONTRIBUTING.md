# Contributing

Thanks for helping improve this project.

## Workflow

1. Open an issue or discussion for larger changes.
2. Fork / branch from `main`.
3. Install dev dependencies: `make dev` or `pip install -e ".[dev]"`.
4. Run `make test` and `make lint` before pushing.
5. Open a pull request or merge request with a clear description and test notes.

## Style

- Python 3.10+.
- Formatting and linting via **Ruff** (`make fmt` / `make lint`).

## Security

Please report sensitive issues via `SECURITY.md` instead of public issues.
